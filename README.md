# Indian Life Simulator

Upload EVERYTHING in this folder to a GitHub repository (branch: main), including the hidden `.github` folder.
If `.github/workflows/build-apk.yml` is missing on GitHub, create that file and paste the contents of `github-workflow-build-apk.yml`.
Then: Actions tab -> Build Android debug APK -> Run workflow -> download the APK from Artifacts.
Full guide: BUILD_APK.md
